১. সিস্টেম চালু করা
----------------------------------------------------------------

প্রতিবার PC চালু করার পর এই ধাপগুলো করবেন:

ধাপ ১ – MySQL চালু করুন
   XAMPP Control Panel খুলুন, তারপর MySQL-এর পাশের "Start" বাটনে
   ক্লিক করুন।

ধাপ ২ – API সার্ভার চালু করুন
   একটি টার্মিনাল (CMD বা PowerShell) খুলে লিখুন:

      cd "D:\MY PRODUCTS\Server_Monitoring\server"
      npm start

   "API + Socket.IO listening on port 5000" লেখা দেখালে বুঝবেন
   সার্ভার চালু হয়েছে। এই টার্মিনালটা বন্ধ করবেন না।

ধাপ ৩ – এই PC-র এজেন্ট চালু করুন
   আরেকটি টার্মিনাল খুলে লিখুন:

      cd "D:\MY PRODUCTS\Server_Monitoring\agent"
      node agent.js

ধাপ ৪ – ড্যাশবোর্ড খুলুন
   ব্রাউজারে খুলুন:  http://localhost:5000

      Username : admin
      Password : 123456

   নেটওয়ার্কের অন্য কম্পিউটার থেকে দেখতে চাইলে খুলবেন:
      http://192.168.11.133:5000
   এর জন্য Windows Firewall-এ port 5000 খোলা থাকতে হবে।


----------------------------------------------------------------
২. নতুন PC বা সার্ভার যুক্ত করা
----------------------------------------------------------------

যে PC মনিটর করতে চান, সেখানে একবার এই কাজগুলো করতে হবে:

 1. সেই PC-তে Node.js ইনস্টল করুন (nodejs.org থেকে)।

 2. "agent" ফোল্ডারটা সেই PC-তে কপি করুন,
    যেমন C:\ServerMonitorAgent -এ।

 3. ফোল্ডারের ভেতরে টার্মিনাল খুলে লিখুন:

       npm install

 4. ফোল্ডারে ".env" নামে একটা ফাইল বানিয়ে এটুকু লিখুন:

       SERVER_URL=http://192.168.11.133:5000
       ENROLL_KEY=SCL-ENROLL-2026

 5. এজেন্ট চালু করুন:

       node agent.js

 6. ১০ সেকেন্ডের মধ্যে PC-টা তার IP সহ ড্যাশবোর্ডে চলে আসবে।

রিস্টার্টের পর এজেন্ট যেন নিজে থেকেই চালু হয়, সেজন্য একবার
এগুলো চালান:

       npm install -g pm2 pm2-windows-startup
       pm2 start agent.js --name sm-agent
       pm2 save
       pm2-startup install

৩. মেনু অনুযায়ী ব্যবহার
----------------------------------------------------------------

>> Overview
   - কতগুলো সার্ভার আছে, কতগুলো Online, Offline, Critical বা
     Warning – উপরের কার্ডে দেখা যায়।
   - প্রতিটি সার্ভারের CPU, RAM আর Disk-এর মিটার (গেজ) দেখা যায়।
   - সবচেয়ে বেশি লোড কোন PC-তে আছে (Top CPU, Top RAM,
     Top Network) দেখা যায়।
   - সাম্প্রতিক সমস্যার তালিকা থাকে।
   - কোনো সার্ভারের কার্ডে ক্লিক করলে তার বিস্তারিত পেজ খুলবে।

>> Servers
   - সব PC-র তালিকা, প্রতিটির লাইভ CPU, RAM, Disk আর
     Network সহ।
   - নাম বা IP দিয়ে খোঁজা যায়; Online, Critical বা Offline
     ফিল্টার করা যায়।
   - "Edit" বাটনে PC-র নাম, Group (যেমন Factory, Head Office)
     আর Location বদলানো যায়।
   - কোনো PC-র মনিটরিং সাময়িক বন্ধ রাখতে চাইলে "Enabled"-এর
     টিক তুলে দিন।

>> সার্ভারের বিস্তারিত পেজ (৪টি ট্যাব)
   Live              : CPU, Temperature, RAM, Swap, Disk আর
                       Network-এর মিটার; শেষ ১৫ মিনিটের লাইভ চার্ট;
                       প্রতিটি ড্রাইভ (C:, D:) কতটা ভরা।
   History & report  : Last hour / Today / 7 days / 30 days /
                       12 months বেছে নিয়ে গড় ও সর্বোচ্চ লোড,
                       Availability %, আর চার্ট।
   Incidents         : এই PC-তে কবে কী সমস্যা হয়েছিল।
   System info       : হার্ডওয়্যার, OS, CPU মডেল, RAM, MAC আর
                       Serial।

>> Incidents (অ্যালার্ট)
   - কোনো সমস্যা হলে সাথে সাথে স্ক্রিনের ডান কোণে পপআপ আসবে,
     সাথে শব্দ হবে।
   - অ্যালার্টের তিন রকম রং:
       লাল   (Critical) : জরুরি – যেমন CPU ৯৫% পার হয়েছে
                          বা PC Offline।
       হলুদ  (Warning)  : সতর্কতা – যেমন Disk ৮৫% পার হয়েছে।
       নীল   (Info)     : হঠাৎ অস্বাভাবিক লোড বেড়েছে।
   - কোনো অ্যালার্টে ক্লিক করলে বিস্তারিত দেখা যায়, সেখানে এই
     কাজগুলো করা যায়:
       Acknowledge : "আমি দেখছি" জানিয়ে রাখা।
       Resolve     : সমস্যা সমাধান হয়েছে বলে চিহ্নিত করা।
       Add note    : কারণ বা কী করা হয়েছে তা লিখে রাখা।
   - সমস্যা নিজে থেকে ঠিক হয়ে গেলে অ্যালার্টও নিজে থেকেই বন্ধ
     (Auto-recovered) হয়ে যায়।

>> Reports
   All servers : সব PC একসাথে – কোন PC-তে কত লোড তার বার
                 চার্ট, আর পুরো টেবিল।
   Server-wise : একটি PC বেছে নিয়ে তার আলাদা রিপোর্ট।
   Incidents   : কোন PC-তে কতবার সমস্যা হয়েছে, আর গড়ে কত
                 সময়ে সমাধান হয়েছে।

   - সময় বাছাই করা যায়: Last hour, Today, 7 days, 30 days,
     12 months, অথবা "Custom" দিয়ে নিজের পছন্দের তারিখ।
   - "CSV" বাটনে Excel ফাইল ডাউনলোড হয়।
   - "Print / PDF" বাটনে প্রিন্ট বা PDF করা যায়।

>> Settings (শুধু admin)
   Alert rules  : কত % হলে অ্যালার্ট দেবে তা ঠিক করা।
                  যেমন CPU-তে Warning ৮০%, Critical ৯৫%, আর
                  "For 60 sec" মানে টানা ৬০ সেকেন্ড থাকলে তবেই
                  অ্যালার্ট দেবে। কোনো নির্দিষ্ট PC-র জন্য আলাদা
                  নিয়মও বানানো যায়।
   SMS gateway  : SMS কোম্পানির API URL, API Key আর মোবাইল
                  নম্বরগুলো (কমা দিয়ে আলাদা করে) দিন। তারপর
                  "Send test SMS" চেপে দেখে নিন SMS আসছে কিনা।
   General      : কোম্পানির নাম, কত সেকেন্ড ডেটা না এলে Offline
                  ধরবে, আর পুরনো ডেটা কতদিন রাখা হবে।
   Agent setup  : নতুন PC যুক্ত করার নিয়ম।
   SMS log      : কোন SMS কাকে গেছে, পৌঁছেছে নাকি ব্যর্থ হয়েছে।
   Audit log    : কে কখন লগইন করেছে বা কী পরিবর্তন করেছে।

>> Users (শুধু admin)
   নতুন ইউজার বানানো যায়। ইউজারের রোল তিন রকম:
     Admin    : সবকিছু করতে পারে।
     Operator : অ্যালার্ট Acknowledge/Resolve করতে পারে,
                সার্ভার এডিট করতে পারে।
     Viewer   : শুধু দেখতে পারে।

৪. SMS চালু করার নিয়ম
----------------------------------------------------------------

 1. Settings -> SMS gateway -এ যান।
 2. আপনার SMS কোম্পানির URL দিন, যেমন:

    https://api.sms-company.com/send?api_key={api_key}&number={to}&message={message}

 3. API Key আর মোবাইল নম্বর দিন,
    যেমন: 8801711000000, 8801811000000
 4. "Enable SMS alerts"-এ টিক দিন।
 5. "Minimum severity" বেছে নিন: শুধু Critical, অথবা
    Warning + Critical।
 6. "Send test SMS" চাপুন। SMS এলে "Save" চাপুন।

৫. ডেমো সার্ভার বন্ধ করা
----------------------------------------------------------------

এখন যে ৫টি নকল সার্ভার দেখছেন (IP 10.99.0.x), সেগুলো শুধু
পরীক্ষার জন্য। আসল ব্যবহার শুরু করার আগে:

 1. যে টার্মিনালে simulator চলছে সেখানে Ctrl + C চাপুন।
 2. Servers -> Edit -> Delete server দিয়ে নকল সার্ভারগুলো
    মুছে দিন।


----------------------------------------------------------------
৬. নিরাপত্তা (অবশ্যই করবেন)
----------------------------------------------------------------

 - Users মেনু থেকে admin-এর পাসওয়ার্ড 123456 বদলে দিন।
 - server\.env ফাইলে JWT_SECRET আর AGENT_ENROLL_KEY বদলে দিন।
   AGENT_ENROLL_KEY বদলালে প্রতিটি এজেন্টের .env ফাইলের
   ENROLL_KEY-ও একই করে দিতে হবে।

৭. সমস্যা হলে
----------------------------------------------------------------

 সমস্যা : ড্যাশবোর্ড খুলছে না
 সমাধান : MySQL আর "npm start" দুটোই চালু আছে কিনা দেখুন।

 সমস্যা : "ECONNREFUSED" লেখা আসছে
 সমাধান : XAMPP-এ MySQL চালু করুন।

 সমস্যা : নতুন PC ড্যাশবোর্ডে আসছে না
 সমাধান : সেই PC-র .env-এ SERVER_URL ঠিক আছে কিনা দেখুন, আর
           মনিটরিং সার্ভারের Firewall-এ port 5000 খুলুন।

 সমস্যা : Temperature-এ "N/A" দেখাচ্ছে
 সমাধান : Windows অনেক PC-তে তাপমাত্রার সেন্সরের তথ্য দেয় না।
           এটা স্বাভাবিক।
