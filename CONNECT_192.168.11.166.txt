অংশ ক – মনিটরিং সার্ভারে (192.168.11.133) একবার যা করবেন
----------------------------------------------------------------

ধাপ ১ – সার্ভার চালু আছে কিনা দেখুন
   - XAMPP Control Panel-এ MySQL চালু (Start) থাকতে হবে।
   - টার্মিনালে API চালু থাকতে হবে:

        cd "D:\MY PRODUCTS\Server_Monitoring\server"
        npm start

ধাপ ২ – Firewall-এ port 5000 খুলে দিন (শুধু একবার)
   Start মেনুতে "PowerShell" লিখে রাইট-ক্লিক করুন, তারপর
   "Run as administrator" দিন। এরপর এই লাইনটা পেস্ট করে
   Enter চাপুন:

   New-NetFirewallRule -DisplayName "Server Monitor 5000" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow

   (এটা না করলে 192.168.11.166 আপনার সার্ভারে ডেটা পাঠাতে
    পারবে না।)

ধাপ ৩ – zip ফাইলটা নিন
   এই ফাইলটা পেনড্রাইভে বা শেয়ার ফোল্ডারে কপি করুন:

        D:\MY PRODUCTS\Server_Monitoring\ServerMonitorAgent.zip

অংশ খ – নতুন PC-তে (192.168.11.166) যা করবেন
----------------------------------------------------------------

ধাপ ৪ – কানেকশন পরীক্ষা করুন
   192.168.11.166 PC-র ব্রাউজারে এই লিংক খুলুন:

        http://192.168.11.133:5000

   লগইন পেজ এলে কানেকশন ঠিক আছে, ধাপ ৫-এ যান।
   পেজ না এলে অংশ ক-এর ধাপ ১ আর ধাপ ২ আবার দেখুন।

ধাপ ৫ – Node.js ইনস্টল করুন
   https://nodejs.org থেকে "LTS" ভার্সন ডাউনলোড করুন, তারপর
   Next -> Next -> Install দিয়ে ইনস্টল করুন।

ধাপ ৬ – zip ফাইলটা Extract করুন
   ServerMonitorAgent.zip ফাইলটা এই PC-তে কপি করুন। তারপর
   রাইট-ক্লিক করে "Extract All" দিন এবং এই জায়গায় রাখুন:

        C:\ServerMonitorAgent

ধাপ ৭ – ইনস্টলার চালান
   C:\ServerMonitorAgent ফোল্ডারে "install-agent.bat"-এ
   রাইট-ক্লিক করে "Run as administrator" দিন।

   এটা দুটো প্রশ্ন করবে। দুটোতেই শুধু Enter চাপবেন:

     Monitoring server URL [http://192.168.11.133:5000]:   <- Enter
     Enroll key [SCL-ENROLL-2026]:                          <- Enter

   এরপর নিচের লেখাগুলো একে একে আসবে:

     [OK] .env saved
     [OK] Server reachable
     ... (প্যাকেজ ইনস্টল হবে, ১-২ মিনিট লাগতে পারে)
     DONE. This PC will appear on the dashboard ...

   শেষে যেকোনো কী চাপলে উইন্ডো বন্ধ হয়ে যাবে।
